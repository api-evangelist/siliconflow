# SiliconFlow (siliconflow)

SiliconFlow is an AI inference cloud serving a broad catalog of open-source models with OpenAI- and Anthropic-compatible APIs. Hosts DeepSeek-R1/V3, Qwen3-Coder, GLM-4.6V, Kimi-K2, MiniMax-M1-80k, gpt-oss-120b, Llama 3.3 70B, FLUX 1.1 Pro, Wan2.2 (video), CosyVoice2 and Fish-Speech (audio). Surfaces include chat, completions, embeddings, reranking, image, video, audio (speech + transcription + voice cloning), files, fine-tuning, and batch.

### SiliconFlow Cloud Platform API
