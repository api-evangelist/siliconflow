# SiliconFlow (siliconflow)

SiliconFlow is an AI inference cloud serving a broad catalog of open-source models with OpenAI- and Anthropic-compatible APIs. Hosts DeepSeek-R1/V3, Qwen3-Coder, GLM-4.6V, Kimi-K2, MiniMax-M1-80k, gpt-oss-120b, Llama 3.3 70B, FLUX 1.1 Pro, Wan2.2 (video), CosyVoice2 and Fish-Speech (audio).

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/siliconflow/refs/heads/main/apis.yml)

## APIs
- **SiliconFlow Cloud Platform API** — OpenAI + Anthropic Messages chat, embeddings, reranking, image, video (Wan2.2), audio (TTS, transcription, voice cloning), files, fine-tuning, batch. Base URL `https://api.siliconflow.com/v1`. [Docs](https://docs.siliconflow.com/) · [Reference](https://docs.siliconflow.com/en/api-reference/chat-completions/chat-completions)
